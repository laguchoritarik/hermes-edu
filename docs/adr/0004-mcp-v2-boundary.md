# 0004 — Use MCP Python SDK v2 as a boundary

Status: **Accepted**  
Date: 2026-09-27

## Context

Hermes should expose and consume standardized tools/resources/prompts.

## Decision

MCP remains an adapter; core use cases remain directly callable.

## Consequences

This decision creates a stable boundary for early implementation. Any reversal should be documented by a superseding ADR.

## Alternatives considered

Alternatives will be expanded when implementation evidence justifies revisiting the decision.
