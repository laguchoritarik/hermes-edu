# 0010 — Default scaffold license is Apache-2.0

Status: **Proposed**  
Date: 2026-09-27

## Context

The intended repository is public and reusable; a permissive license with an explicit patent grant is desirable.

## Decision

The scaffold ships Apache-2.0. Maintainers may replace it before the first public release.

## Consequences

This decision creates a stable boundary for early implementation. Any reversal should be documented by a superseding ADR.

## Alternatives considered

Alternatives will be expanded when implementation evidence justifies revisiting the decision.
